¿Qué hace este módulo?

Permite cargar automáticamente Despachos de Aduana (Formulario Oficial OM-1993) desde PDF mediante un asistente (wizard), generando en forma automática la Factura de Proveedor en Odoo con balance contable perfecto y conformidad con el validador ARCA (RG 3685).

Características principales

Carga automática desde PDF
Subí el PDF del despacho y el wizard extrae todos los valores fiscales sin intervención manual.
Desglose fiscal completo
Clasifica automáticamente Aranceles, Tasas Estadísticas, IVA Crédito Fiscal 21%, Percepciones de Ganancias (RG 830), Percepciones de IIBB Provinciales y SIM IMPO (No Gravado).
Ajuste atómico quirúrgico
Garantiza que el asiento contable cierre perfectamente usando base inversa de IVA, sin diferencias de centavos ni errores de redondeo.
Validador ARCA (RG 3685)
Genera el TXT con formato exacto: 325 chars CBTE + 50 chars ALICUOTAS. SIM IMPO se registra como No Gravado (C10) con alícuota 0 (C12).

Requisitos

  • Odoo 15.0 Community o Enterprise
  • Módulos: account l10n_ar
  • Python: pdfplumber
  • Localización argentina configurada (plan de cuentas AR)

Instalación

  1. Instalar dependencia Python: pip install pdfplumber
  2. Copiar el módulo en la carpeta addons de Odoo
  3. Actualizar lista de módulos y instalar Argentina Importación Aduana
  4. Configurar las cuentas contables en Contabilidad → Configuración → Ajustes
