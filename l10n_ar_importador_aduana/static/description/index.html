Que hace este modulo?

Permite cargar automaticamente Despachos de Aduana (Formulario Oficial OM-1993) desde PDF mediante un asistente (wizard), generando en forma automatica la Factura de Proveedor en Odoo con balance contable perfecto y conformidad con el validador ARCA (RG 3685).

Caracteristicas principales

Carga automatica desde PDF Subi el PDF del despacho y el wizard extrae todos los valores fiscales sin intervencion manual.
Desglose fiscal completo Clasifica automaticamente Aranceles, Tasas Estadisticas, IVA Credito Fiscal 21%, Percepciones de Ganancias (RG 830), Percepciones de IIBB Provinciales y SIM IMPO (No Gravado).
Ajuste atomico quirurgico Garantiza que el asiento contable cierre perfectamente usando base inversa de IVA, sin diferencias de centavos ni errores de redondeo.
Validador ARCA (RG 3685) Genera el TXT con formato exacto: 325 chars CBTE + 50 chars ALICUOTAS. SIM IMPO se registra como No Gravado (C10) con alicuota 0 (C12).

Requisitos

  • Odoo 15.0 Community o Enterprise
  • Modulos: account l10n_ar
  • Python: pdfplumber
  • Localizacion argentina configurada (plan de cuentas AR)

Instalacion

  1. Instalar dependencia Python: pip install pdfplumber
  2. Copiar el modulo en la carpeta addons de Odoo
  3. Actualizar lista de modulos e instalar Argentina Importacion Aduana
  4. Configurar las cuentas contables en Contabilidad → Configuracion → Ajustes
