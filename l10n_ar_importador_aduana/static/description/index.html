¿Qué hace este módulo?

Permite cargar automáticamente Despachos de Aduana (Formulario Oficial OM-1993) desde PDF mediante un asistente (wizard), generando en forma automatizada la Factura de Proveedor en Odoo con balance contable perfecto y conformidad con el validador ARCA (RG 3685).

Características principales

Carga Automática desde PDF

Subí el PDF del despacho de ARCA y el wizard extraerá todos los valores fiscales sin intervención ni transcripción manual.

Desglose Fiscal Completo

Clasifica automáticamente Aranceles, Tasas Estadísticas, IVA Crédito Fiscal, Percepciones de Ganancias (RG 830), IIBB Provinciales y SIM IMPO.

Ajuste Atómico Quirúrgico

Garantiza que el asiento contable cierre perfectamente usando base inversa de IVA, eliminando diferencias de centavos y errores de redondeo.

Validación Contable RG 3685

Genera las líneas de impuestos respetando la estructura oficial requerida para el reporte de compras y el validador contable de ARCA.

Requisitos del Sistema

  • Odoo 15.0 Community o Enterprise.
  • Módulos: account y l10n_ar instalados.
  • Python: pdfplumber instalado en el servidor.
  • Localización argentina configurada con plan de cuentas activo.

Instalación paso a paso

  1. Instalá la dependencia Python: pip install pdfplumber
  2. Copiá la carpeta del módulo dentro de tu ruta de addons de Odoo.
  3. Activá el modo desarrollador en Configuración General.
  4. Ir a Aplicaciones y hacer clic en "Actualizar lista de módulos".
  5. Buscar l10n_ar_importador_aduana y presionar "Instalar".
