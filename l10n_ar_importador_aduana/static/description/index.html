¿Qué hace este módulo?

Permite cargar automáticamente Despachos de Aduana (Formulario Oficial OM-1993) desde PDF mediante un asistente (wizard), generando en forma automatizada la Factura de Proveedor en Odoo con balance contable perfecto y conformidad con el validador ARCA (RG 3685).

Características principales

Carga Automática desde PDF

Subí el PDF del despacho de ARCA y el wizard extraerá de forma directa todos los valores fiscales sin intervención ni transcripción manual.

Desglose Fiscal Completo

Clasifica automáticamente Aranceles, Tasas Estadísticas, IVA Crédito Fiscal, Percepciones de Ganancias (RG 830), IIBB Provinciales y SIM IMPO.

Ajuste Atómico Quirúrgico

Garantiza que el asiento contable cierre perfectamente usando base inversa de IVA, eliminando diferencias de centavos ni errores de redondeo.

Validación Contable RG 3685

Genera las líneas de impuestos respetando la estructura oficial requerida para el posterior reporte de compras y el validador contable de ARCA.

Requisitos del Sistema

  • Odoo versión 15.0 (Compatible con ediciones Community y Enterprise).
  • Módulos base requeridos instalados: account (Contabilidad) y l10n_ar (Localización Argentina).
  • Librería de Python del servidor: pdfplumber instalada en el entorno.
  • Localización argentina configurada correctamente con su plan de cuentas activo.

Instalación paso a paso

  1. Instalá la dependencia de Python requerida ejecutando en tu servidor: pip install pdfplumber
  2. Copiá la carpeta del módulo descomprimida dentro de tu ruta de addons de Odoo.
  3. Activá el modo desarrollador en la configuración general de tu base de datos Odoo.
  4. Dirigite al menú de Aplicaciones y hacé clic en "Actualizar lista de módulos".
  5. Buscá el módulo técnico como l10n_ar_importador_aduana y presioná el botón "Instalar".
